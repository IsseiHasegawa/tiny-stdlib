# tiny-stdlib

A small C++ library that reimplements common standard library components from scratch for learning.

## Goals

* Learn how C++ standard library components work internally
* Practice memory management, RAII, templates, and move semantics
* Build higher-level features using self-implemented components

## Planned

* `allocator`
* `unique_ptr`
* `shared_ptr`
* `weak_ptr`
* `vector`
* `string`
* `array`
* `list`
* `optional`
* basic algorithms and iterators

## Note

This project is for learning and experimentation, not as a replacement for the C++ standard library.
